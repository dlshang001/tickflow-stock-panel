## 零、前置知识

### 必懂术语

| 术语 | 含义 |
|------|------|
| **MA / 均线** | 移动平均线。MA5 = 最近 5 天收盘价的平均值。短期（MA5/MA10）、中期（MA20）、长期（MA60） |
| **金叉 🟢** | 短期均线**上穿**长期均线 → 趋势转多（买入信号） |
| **死叉 🔴** | 短期均线**下穿**长期均线 → 趋势转空（卖出信号） |
| **RSI** | 相对强弱指标，0~100。< 30 = 超卖（跌太多可能反弹），> 70 = 超买（涨太多可能回调） |
| **MACD** | 趋势跟随指标。DIF（快线）- DEA（慢线）交叉产生买卖信号，比均线更可靠 |
| **量比** | 当日成交量 ÷ 过去 5 日平均成交量。> 1 = 放量（资金活跃），< 1 = 缩量（交易清淡） |
| **换手率** | 当日成交量 ÷ 流通股本。反映股票换手活跃度，越高越活跃 |
| **动量** | N 日内价格涨跌幅百分比，衡量趋势强度 |
| **布林带** | 中轨 = MA20，上轨 = MA20 + 2σ，下轨 = MA20 - 2σ。轨道收窄预示变盘 |
| **EMA** | 指数移动平均线。相比 MA，近期价格权重更大，反应更快 |

## 一、均线趋势类（4 个）

### 1. MA 金叉 (`ma_golden_cross`)

> **一句话**：短期均线上穿中期均线，是上涨趋势启动的经典信号。

```
  价格
   ↑
   │                            ★ ← 金叉时刻！MA5 上穿 MA20
   │                         ╱  ╲
   │                      ╱       ╲___ MA5（短期，变化快）
   │                   ╱          ╱
   │     ───────────╱──────────╱────  MA20（中期，变化慢）
   │              ╱
   │  ──────────╱───────────────────  MA60（长期，确认大方向）
   │
   │  [震荡整理] ←→ [金叉 → 上涨趋势启动]
   │
   └─────────────────────────────────────────→ 时间

   成交
   量 ↑      ┌─┐
      │   ┌──┘ └──┐     ← 金叉当天放量确认（量比 ≥ 1.2）
      │   │       └─┐
      │───┘         └─────────────────  5日均量
      └─────────────────────────────────→ 时间
```

**适用场景**：发现正在从震荡转向上涨的个股

**买入条件（3 个全部满足）**：

| # | 条件 | 要求 | 含义 |
|---|------|------|------|
| ① | signal_ma_golden_5_20 | MA5 当日上穿 MA20 | 短期趋势转强 |
| ② | vol_ratio_5d ≥ 1.2 | 量比达标 | 有资金参与，非假突破 |
| ③ | close > ma60 | 收盘在 MA60 上方 | 中长期趋势向上 |

**参数**：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 最低量比 | 1.2 | 0.5 ~ 5.0 | 调低 → 更敏感，调高 → 更可靠 |

**卖出信号**：`signal_ma_dead_5_20`（MA5 下穿 MA20 死叉）

**风控**：止损 -6% / 最长 15 天

**评分权重**：20日动量(0.5) + 量比(0.3) + 涨幅(0.2)

### 2. 均线多头 (`bullish_alignment`)

> **一句话**：四条均线从短到长依次排列、方向一致向上，是最强的多头形态。

```
  价格
   ↑
   │         ╱ MA5  ────────────── 最上面（短期最强）
   │        ╱ MA10 ──────────────
   │       ╱ MA20 ──────────────
   │      ╱ MA60 ────────────── 最下面（长期托底）
   │     ╱
   │    ╱  ★ 多头排列：MA5 > MA10 > MA20 > MA60
   │   ╱   所有买入者都处于盈利状态
   │  ╱    → 持股者不愿卖，场外资金愿意追
   │ ╱
   │╱
   └────────────────────────────────────→ 时间

   概   MA5
   念   ↓  >  MA10
   图   ↓  ↓  >  MA20
        ↓  ↓  ↓  >  MA60
        ↑  ↑  ↑      ↑
       短期          长期
```

**适用场景**：寻找正处于完美上涨趋势中的强势股

**买入条件（4 个全部满足）**：

| # | 条件 | 含义 |
|---|------|------|
| ① | MA5 > MA10 | 短期高于次短期 |
| ② | MA10 > MA20 | 中期排列正确 |
| ③ | MA20 > MA60 | 中期在长期之上 |
| ④ | momentum_20d > 0 | 20 日总体上涨 |

**参数**：无用户可调参数（纯形态判断）

**卖出信号**：`signal_ma_dead_5_20` 或 `signal_ma20_breakdown`

**风控**：止损 -6% / 最长 20 天

**评分权重**：60日动量(0.4) + 20日动量(0.3) + 换手率(0.3)

### 3. 均线回踩反弹 (`pullback_ma20_bounce`)

> **一句话**：上涨趋势中股价跌回 MA20 附近时低吸买入，是一种"顺势回调"策略。

```
  价格
   ↑
   │    ╱╲
   │   ╱  ╲    ← 涨多了，短暂回调
   │  ╱    ╲
   │ ╱      ╲       ★ ← 回踩 MA20 支撑位，止跌收阳
   │╱        ╲    ╱
   │          ╲╱╱╱───  MA20（支撑线）
   │          ╱
   │    ────╱────────  MA60（确认趋势向上）
   │
   │  [上涨] → [回调] → [回踩MA20 反弹!]
   │
   └──────────────────────────────────────→ 时间

   ★ 关键判断：
   ① 股价在 MA20 ± 2% 范围内（摸到了支撑位）
   ② MA5 > MA20（短期方向没坏）
   ③ MA20 > MA60（大方向向上）
   ④ 当天收阳（确认反弹开始，不是继续跌）
```

**适用场景**：你看好一只上涨中的股票，想在它回调时低吸上车

**买入条件（4 个全部满足）**：

| # | 条件 | 含义 |
|---|------|------|
| ① | close 在 MA20 × (1 ± proximity) | 股价靠近支撑位 |
| ② | MA5 > MA20 | 短期仍强于中期 |
| ③ | MA20 > MA60 | 中长期趋势向上 |
| ④ | change_pct > 0（收阳） | 确认反弹而非继续跌 |

**参数**：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 均线偏离度 | 2% | 0.5% ~ 5% | 允许股价偏离 MA20 的距离 |

**卖出信号**：`signal_ma20_breakdown` 或 `signal_ma_dead_5_20`

**风控**：止损 -5% / 最长 15 天

**评分权重**：60日动量(0.4) + 涨幅(0.3) + 20日动量(0.3)

### 4. 缩量回踩 (`pullback_to_support`)

> **一句话**：回踩 MA20 + **成交萎缩** + 趋势向上，是调整洗盘接近尾声的信号。

```
  价格
   ↑
   │    ╱╲
   │   ╱  ╲
   │  ╱    ╲     ← 股价回踩 MA20
   │ ╱      ╲
   │╱        ╲___  ★ 回调到MA20附近，但成交量明显萎缩
   │          ╱    → 说明卖盘不多了，洗盘接近尾声
   │    ────╱───────  MA20
   │
   └──────────────────────────────────────→ 时间

   成交
   量 ↑
      │  ╲
      │   ╲___          ← 量越来越小（缩量！）
      │       ╲___      量比 < 0.8
      │           ╲___
      │               ╲___
      └─────────────────────→ 时间

   ★ "缩量回踩"的核心逻辑：
     如果真要大跌，应该是放量杀跌。
     缩量回调 → 卖盘衰竭 → 主力在"洗盘"而非"出货" → 调整后大概率继续涨
```

**适用场景**：寻找洗盘接近尾声、即将再次上涨的股票

**买入条件（5 个全部满足）**：

| # | 条件 | 含义 |
|---|------|------|
| ① | close 在 MA20 ± proximity | 靠近支撑位 |
| ② | vol_ratio_5d < 0.8 | **缩量！卖盘衰竭** |
| ③ | close > MA60 | 中长期趋势向上 |
| ④ | momentum_20d > 0 | 20 日趋势向上 |

**参数**：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 均线偏离度 | 2% | 1% ~ 5% | 回踩 MA20 的容忍范围 |
| 最大量比 | 0.8 | 0.2 ~ 1.5 | 越低缩量越明显 |

**卖出信号**：`signal_ma20_breakdown`

**风控**：止损 -5% / 最长 20 天

**评分权重**：60日动量(0.4) + 20日动量(0.3) + 换手率(0.3)

## 二、指标金叉类（2 个）

### 5. MACD 金叉放量 (`macd_golden`)

> **一句话**：MACD 金叉 + 放量确认，比普通均线金叉更可靠。

```
  MACD 指标
   ↑                         ★ ← DIF 上穿 DEA（金叉）
   │                      ╱  ╱
   │                   ╱    ╱  ← DIF（快线）
   │     ───────────╱─────╱────  DEA（慢线）
   │              ╱     ╱
   │  ──────────╱─────╱────────
   │           ╱    ╱
   │          ╱   ╱
   │         ╱  ╱
   │        ╱ ╱
   │       ╱╱
   └────────────────────────────→ 时间
            ↑               ↑
       [MACD 柱在零轴下] → [金叉后翻到零轴上]

   成交
   量 ↑      ┌─┐
      │   ┌──┘ └──┐     ← 金叉当天放量 ≥ 1.5 倍
      │   │       └─┐   资金积极参与确认
      │───┘         └───────────  5日均量
      └─────────────────────────→ 时间

   ★ MACD vs MA 金叉：
     MACD 包含了对价格变化速度（动能）的考量，
     能过滤掉一些均线金叉的假信号，但反应慢半拍。
```

**适用场景**：想要比 MA 金叉更精准的趋势反转确认信号

**买入条件（2 个全部满足）**：

| # | 条件 | 含义 |
|---|------|------|
| ① | signal_macd_golden | DIF 上穿 DEA（MACD 金叉） |
| ② | vol_ratio_5d ≥ 1.5 | 放量确认 |

**参数**：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 最低量比 | 1.5 | 0.5 ~ 5.0 | 放量要求比 MA 金叉更高 |

**卖出信号**：`signal_macd_dead`（MACD 死叉）

**风控**：止损 -7% / 最长 20 天

**评分权重**：60日动量(0.4) + 量比(0.3) + 涨幅(0.3)

```
   │  ╱    ╲╱    ╲ ╱   │
   │ ╱            ╲╱    │
   │╱                   │← 布林带中轨 = MA20
   │                    │
   │                    │← 布林带下轨（支撑线）
   └──────────────────────────────→ 时间

   布林带收窄 → 突破上轨
   ┌──────────────────────┐
   │  ||  →  |||  →  ┌┐  │  轨道收窄 = "暴风雨前的宁静"
   │  ||  →  |||  →  ││  │  突破后往往伴随加速行情

   └──────────────────────┘
```

**适用场景**：寻找即将爆发性上涨的股票

**风控**：止损 -6% / 最长 15 天

## 三、超跌反弹类（3 个）

### 7. 超跌反弹 (`oversold_bounce`)

> **一句话**：RSI 进入超卖区（< 30）后，当天收阳且放量，是抄底反弹信号。

```
  RSI 指标
  100↑
     │
   70├ ─ ─ ─ ─ ─ ─ ← 超买区（涨太多了）
     │    ╲
   50├     ╲         ← 正常区间
     │      ╲
   30├ ─ ─ ─ ╲ ─ ─ ← 超卖区（跌太多了）
     │        ╲
     │         ╲_____ ★ RSI < 30，进入超卖！
   0 └─────────────────────────→ 时间

   价格
   ↑
   │  ╲
   │   ╲         ★ ← RSI < 30 + 收阳（红K线）+ 放量
   │    ╲      ╱     = 超跌反弹信号！
   │     ╲   ╱
   │      ╲╱╱
   │       ╲
   └─────────────────────────→ 时间

   ★ 核心思想：
     "跌多了自然会反弹" —— 但需要确认（收阳 + 放量）
     避免在下跌中途接飞刀
```

**适用场景**：连续下跌后寻找反弹起点

**买入条件（3 个全部满足）**：

| # | 条件 | 含义 |
|---|------|------|
| ① | RSI(14) < 30 | 超卖 |
| ② | close > open（收阳） | 有资金开始买入 |
| ③ | vol_ratio_5d ≥ 1.2 | 放量确认反弹力度 |

**参数**：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| RSI 上限 | 30 | 10 ~ 50 | 越低抄底越保守 |
| 最低量比 | 1.2 | 0.5 ~ 5.0 | 放量要求 |

**卖出信号**：`signal_ma20_breakdown`

### 10. 连板股 (`consecutive_limit_ups`)

> **一句话**：筛选当天涨停且连续涨停 ≥ 2 天的股票，追最强龙头。

```
  价格（K线图）
```

```
   │  买方意愿极强 → 愿意以高于昨收价买入           │
   │  开盘后继续涨 → 买盘持续，不是"一日游"         │
   │  如果高开低走 → 说明是陷阱（利好出货）          │
   └─────────────────────────────────────────────┘
```

**适用场景**：开盘后快速发现当天可能走强的股票

**买入条件（3 个全部满足）**：

| # | 条件 | 含义 |
|---|------|------|
| ① | open > prev_close × (1 + 3%) | 高开 > 3% |
| ② | close > open | 高开后没回落 |
| ③ | change_pct > 3% | 全天涨幅确认 |

**参数**：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 最低高开 | 3% | 1% ~ 10% | 高开幅度要求 |
| 最低涨幅 | 3% | 1% ~ 10% | 全天涨幅要求 |

**卖出信号**：`signal_ma20_breakdown`

**风控**：止损 -5% / 最长 10 天

**评分权重**：涨幅(0.4) + 振幅(0.2) + 成交额(0.4)

### 18. 高换手拉升 (`high_turnover_surge`)

> **一句话**：换手率 > 5% + 涨幅 > 3%，资金高度活跃且方向向上。

```
  换手率 %
   ↑
  10├                  ┌─┐
    │      ┌─┐  ┌─┐   │ │  ★ ← 换手 > 5%
   8├  ┌─┐ │ │  │ │ ┌─┐│ │     资金高度活跃
    │  │ │ │ │┌┐│ │ │ ││ │
   6├  │ │ │ ││││ │ │ ││ │
    │  │ │┌┘ └┘└┘ └─┘└┘└─┘
   4├──┴─┴────────────────────  正常换手区间
    │
    └────────────────────────→ 时间

   价格
   ↑
   │                         ╱  ← 同时涨幅 > 3%
   │                    ╱   ╱
   │               ╱   ╱   ╱
   │          ╱   ╱   ╱   ╱
   │     ╱   ╱   ╱   ╱   ╱
   │╱   ╱   ╱   ╱   ╱   ╱
   └────────────────────────→ 时间

   ★ 高换手 + 上涨 = 资金看多，积极买进
   ★ 高换手 + 下跌 = 资金出逃，要远离
```

**适用场景**：寻找大量资金参与、交易热门的方向明确的股票

**买入条件（2 个全部满足）**：

| # | 条件 | 含义 |
|---|------|------|
| ① | turnover_rate > 5% | 换手活跃 |
| ② | change_pct > 3% | 方向向上 |

**参数**：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 最低换手率 | 5% | 1% ~ 20% | 越高越活跃 |
| 最低涨幅 | 3% | 1% ~ 10% | 方向确认 |

**卖出信号**：`signal_ma20_breakdown`

**风控**：止损 -5% / 最长 10 天

**评分权重**：换手率(0.4) + 涨幅(0.3) + 5日动量(0.3)

## 七、评分引擎详解

### 7.1 算法：Min-Max 归一化 + 加权求和

```
步骤1: 归一化
┌──────────────────────────────────────────────────────┐
│  normalized = (当前值 - 该列最小值) / (最大值 - 最小值)  │
│  如果全等 → 统一给 0.5（不好不坏）                      │
│  结果范围 [0, 1]                                       │
└──────────────────────────────────────────────────────┘

步骤2: 加权求和
┌──────────────────────────────────────────────────────┐
│  weighted = Σ( normalized × 权重 / 权重总和 ) × 100     │
│  输出范围 [0, 100]                                     │
└──────────────────────────────────────────────────────┘
```

### 7.2 实例计算

假设「MA 金叉」选出 3 只候选股：

| 股票 | 20日动量 | 量比 | 涨幅 |
|------|---------|------|------|
| A 股 | 15%     | 2.5  | 4%   |
| B 股 | 8%      | 1.5  | 3%   |
| C 股 | 20%     | 3.0  | 6%   |

权重：`momentum_20d: 0.5, vol_ratio_5d: 0.3, change_pct: 0.2`

**(1) 归一化 20 日动量**（min=8, max=20）：
- A: (15-8)/(20-8) = 0.583
- B: (8-8)/(20-8) = 0
- C: (20-8)/(20-8) = 1.0

**(2) 归一化量比**（min=1.5, max=3.0）：
- A: (2.5-1.5)/(3.0-1.5) = 0.667
- B: (1.5-1.5)/(3.0-1.5) = 0
- C: (3.0-1.5)/(3.0-1.5) = 1.0

**(3) 归一化涨幅**（min=3, max=6）：
- A: (4-3)/(6-3) = 0.333
- B: (3-3)/(6-3) = 0
- C: (6-3)/(6-3) = 1.0

**(4) 加权求和**：

| 股票 | 动量×0.5 | 量比×0.3 | 涨幅×0.2 | **总分** |
|------|---------|---------|---------|---------|
| A    | 0.292   | 0.200   | 0.067   | **55.9** |
| B    | 0       | 0       | 0       | **0**   |
| C    | 0.5     | 0.3     | 0.2     | **100** |

> 📌 得分是**相对排名**。0 分 = 在候选股里各项垫底，100 分 = 各项最强。

| 策略 | 指标1（权重） | 指标2（权重） | 指标3（权重） | 指标4 |
|------|------------|------------|------------|------|

| 缩量回踩 | 60日动量(0.4) | 20日动量(0.3) | 换手率(0.3) | - |
| MACD金叉放量 | 60日动量(0.4) | 量比(0.3) | 涨幅(0.3) | - |
| 布林突破 | 量比(0.4) | 涨幅(0.3) | 20日动量(0.3) | - |
| 超跌反弹 | 涨幅(0.3) | 量比(0.3) | 5日动量(0.2) | RSI(0.2) |

## 八、信号引擎详解

### 8.1 完整信号定义（16 个内置信号）

每天对每只股票计算并存储为布尔值（True/False），策略依赖这些信号判断买卖时机。

```
均线类 (5个)
├─ signal_ma_golden_5_20    今天MA5>MA20 且 昨天MA5≤MA20
├─ signal_ma_dead_5_20      今天MA5<MA20 且 昨天MA5≥MA20
├─ signal_ma_golden_20_60   今天MA20>MA60 且 昨天MA20≤MA60
├─ signal_ma20_breakout     今天收盘>MA20 且 昨天收盘≤MA20
└─ signal_ma20_breakdown    今天收盘<MA20 且 昨天收盘≥MA20

MACD类 (2个)
├─ signal_macd_golden       DIF上穿DEA（金叉）
└─ signal_macd_dead         DIF下穿DEA（死叉）

布林类 (2个)
├─ signal_boll_breakout_upper   收盘 > 布林上轨
└─ signal_boll_breakdown_lower  收盘 < 布林下轨

极值/量能 (3个)
├─ signal_n_day_high       收盘 ≥ 60日最高价
├─ signal_n_day_low        收盘 ≤ 60日最低价
└─ signal_volume_surge     量比 ≥ 2.0

涨跌停类 (4个信号 + 1个统计列)
├─ signal_limit_up              收盘 ≈ 涨停价（误差 < 0.005）
├─ signal_limit_down            收盘 ≈ 跌停价
├─ signal_limit_down_recovery   触及跌停但最终未跌停且收阳
├─ signal_broken_limit_up       触及涨停但最终未封住（炸板）
└─ consecutive_limit_ups        连续涨停天数（整数，非布尔）
```

### 8.2 关键信号触发逻辑（代码层面）

```python
# MA 金叉 — 必须同时满足「今天」和「昨天」两个条件
signal_ma_golden_5_20 = (
    (今日MA5 > 今日MA20) & (昨日MA5 <= 昨日MA20)
)

# MACD 金叉
signal_macd_golden = (
    (今日DIF > 今日DEA) & (昨日DIF <= 昨日DEA)
)

# 突破布林上轨 — 只需要今天条件
signal_boll_breakout_upper = (收盘 > 布林上轨)

# 涨停 — 收盘价与理论涨停价误差 < 0.005 元
# 理论涨停价 = round(前日收盘 × (1 + 涨跌幅限制), 2)
signal_limit_up = (|收盘 - 理论涨停价| < 0.005)
```

### 8.3 各板块涨跌幅限制识别

| 板块 | 涨跌幅限制 | 识别规则 |
|------|----------|---------|
| 主板 | 10% | 60开头 / 00或001开头 |
| 创业板 | 20% | 300或301开头 |
| 科创板 | 20% | 688开头 |
| 北交所 | 30% | .BJ结尾 |
| ST股 | 5% | 名称含ST |

### 9.1 Stage 1 执行顺序

```
全部A股 (~5000只)
        ↓
   ① 价格过滤  (默认: 3~300元)
        ↓
   ② 市值过滤  (默认: ≥10亿)
        ↓

        ↓

        ↓
```

## 十一、新手使用建议

### 按风险偏好选择

```
保守型 → 低波动龙头、量价齐升、MA 金叉
均衡型 → + 均线多头、均线回踩、MACD 金叉、缩量回踩
进取型 → + 趋势突破、布林突破、超跌反弹/反转
激进型 → + 连板、断板反包、逼近涨停、新低反转
```

### 按市场环境选择

| 大盘环境 | 推荐策略 |
|---------|---------|
| 🐂 牛市（单边上涨） | 趋势突破、均线多头、量价齐升 |
| 📊 震荡市（上下波动） | 缩量回踩、均线回踩反弹、低波动龙头 |
| 🐻 熊市（单边下跌） | 超跌反弹、超跌反转（轻仓/观望） |
| 🎯 题材炒作期 | 连板股、断板反包、逼近涨停 |

### 风控铁律

1. **止损永远不关**：所有策略内置了止损，这是保命的关键。回测中 90% 的亏损来自不止损。
2. **T+1 风险**：A 股今天买明天才能卖，短线策略（连板、涨停类）比看起来更危险。
3. **不要单吊一个策略**：同时使用 2~3 个不同类型策略（如趋势类 + 低吸类），分散风险。
4. **先不改参数**：默认参数经过优化，新手先跑几周熟悉了再微调。
5. **大盘不好时空仓**：任何策略在大盘单边暴跌时胜率都会大幅下降。

### 参数调节方向参考

| 策略类型 | 调高参数 | 效果 |
|---------|---------|------|
| 量比类 | 最低量比 ↑ | 选股更严格，假信号更少，但机会也少 |
| 超跌类 | RSI 上限 ↓ | 抄底更保守，价格更低，但可能错过反弹 |
| 连板类 | 最少连板 ↑ | 只追最强龙头，但数量极少 |
| 突破类 | 量比 ↓ | 选股更多元，但假突破增加 |
